# ⚽ Quiniela Mundial 2026

Una aplicación web de quiniela para el Mundial de Fútbol 2026 con clasificación en tiempo real, almacenamiento compartido y actualización automática de resultados mediante API-Football y Supabase.

![Banner](https://img.shields.io/badge/Mundial-2026-green)
![Supabase](https://img.shields.io/badge/Supabase-Backend-success)
![API-Football](https://img.shields.io/badge/API--Football-Live%20Data-blue)
![JavaScript](https://img.shields.io/badge/JavaScript-ES6-yellow)

---

## 🌟 Características

✅ Pronósticos multijugador

✅ Marcador exacto o ganador del partido

✅ Clasificación automática

✅ Datos reales del Mundial 2026

✅ Actualización mediante API-Football

✅ Backend Serverless con Supabase

✅ Edge Functions para sincronización automática

✅ Diseño responsive

## 🚀 Instalación

```bash
git clone https://github.com/miguel260383/quiniela-mundial-2026.git
```

Abrir:

```bash
index.html
```

o ejecutar con Live Server.

---

## 🔄 Actualización de resultados

Los partidos se sincronizan automáticamente desde API-Football mediante una Edge Function desplegada en Supabase.
